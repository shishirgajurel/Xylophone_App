# Xylophone App

A colourful xylophone that plays a different note for each key.

> Built in 2021–2022 while I was learning Flutter and mobile development in Nepal. Kept here as part of my learning history.

## Features
- Plays sounds with the audioplayers package

## Run it
Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install).
```bash
flutter pub get
flutter run
```

## Tech
Flutter · Dart · audioplayers
